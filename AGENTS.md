# Трекер задач

После правок запусти `mise run check` и `mise run test`. Для тестов укажи в `TEST_DATABASE_URL` отдельную базу PostgreSQL, где тест может создать временную схему. Порядок запуска учебных примеров описан в README.md.

При изменении зависимостей обнови `uv.lock` командой `uv lock`. Миграции проверяй на пустой базе и на базе с задачей, сохранённой до переименования столбца.
